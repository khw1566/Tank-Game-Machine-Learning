# 전차 장갑·피해 모델 (tanks/)

티거 I, M4 셔먼(75mm), T-34/76 세 전차를 실제 자료를 바탕으로 **단순하지만 판정 가능한** 수준으로 모델링한다.
물리엔진 없이 해석적으로 계산하므로 헤드리스 학습에서도 빠르고, 시드를 고정하면 결과가 완전히 재현된다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `tank_database.gd` | 3종 전차 제원(장갑, 포, 기동, 승무원·모듈 배치). 출처 주석 포함 |
| `tank_spec.gd`, `gun_spec.gd` | 제원 데이터 구조. `to_dict()` 로 JSON 내보내기 |
| `hit_geometry.gd` | 탄 궤적 → 명중 부위(구역)·입사각 계산 (차체 상자 + 회전 포탑 상자) |
| `ballistics.gd` | 거리별 관통력, 유효장갑, 도탄, 관통확률 |
| `tank_damage_state.gd` | 전차 1대의 승무원·모듈·화재·탈출 상태, 성능 배율, ML 관측 벡터 |
| `damage_model.gd` | 사격 1발 판정 진입점 `DamageModel.resolve_shot()` |
| `tank.gd` | 게임 속 전차 노드(조작 입력 → 궤도 구동·포탑·사격) |
| `tests/run_tank_tests.gd` | 검증 + 보고서용 표 출력 |
| `data/*.json` | 제원 및 관통확률표 내보내기 결과(`-- --export`) |

## 판정 절차 (사격 1발)

1. **명중 부위**: 표적 로컬 좌표로 바꾼 탄 궤적을 차체 상자·포탑 상자와 교차시켜 처음 맞는 면을 찾는다.
   면 + 높이로 11개 구역 중 하나를 고른다:
   `hull_front_upper/lower, hull_side_upper/lower, hull_rear, hull_top, hull_bottom, turret_front/side/rear/top`.
   포탑은 `turret_yaw` 만큼 회전된 상자이므로 포탑을 돌리면 맞는 면도 바뀐다.
2. **입사각**: 상자 면의 법선을 장갑판 경사(수직 기준 °)만큼 위로 기울인 실제 판 법선과 탄 방향의 각.
   수평 각도(차체를 비튼 각)와 수직 경사가 3차원으로 함께 반영된다 → 티거의 "티타임/정오 자세"가 자연스럽게 재현됨.
3. **유효장갑** = 두께 / cos(입사각 − 피모 보정). 구경이 판 두께의 2배를 넘으면(과구경) 보정이 커진다.
4. **도탄**: 입사각이 포별 임계각(약 68~70°) ±5° 구간에서 확률적으로 도탄. 구경 ≥ 3×두께면 도탄 없음.
5. **관통 판정**: 거리별 평균 관통력 × (1 + N(0, 5%)) > 유효장갑 이면 관통.
6. **내부 피해(관통 시)**:
   - 파편 원뿔: 진입점에서 반대편 벽까지, 진행할수록 넓어지는 원뿔 안의 승무원·모듈(구로 근사)이 거리에 따라 확률적으로 피해.
   - 작약 폭발: 지연신관 거리(약 1~1.2m) 지점에서 작약량에 비례한 반경으로 추가 피해.
   - 승무원: 정상 → 부상 → 전사. 모듈: 정상 → 손상 → 파괴.
   - 2차 효과: 탄약고 피격 → 유폭 확률, 연료탱크 → 화재 확률(가솔린 > 디젤), 엔진 → 화재 확률.
   - 탈출(사기): 관통 1회마다 기본 5% + 사상자 1명당 15% (+ 기동불능이면 15%).
7. **비관통 효과**: 하부 측면·하부 전면 명중 시 35% 확률로 궤도 손상, 포탑 정면 명중 시 소량 확률로 포/선회링 손상.
8. **무력화 판정** (`knockout_cause`):
   `ammo_detonation`(유폭), `fire`(화재), `crew_bailed_out`(탈출), `crew_casualties`(생존 1명 이하),
   `firepower_and_mobility_lost`(사격도 기동도 불가). 궤도만 끊긴 전차는 **기동불능이지만 여전히 사격 가능** → 전투 중.

### 승무원 역할 재배정
생존자가 우선순위(포수 > 조종수 > 장전수 > 전차장 > 무전수)에 따라 빈자리를 메운다.
자기 자리가 아니면 작업시간 ×1.3, 부상이면 ×1.5. 장전수가 없으면 포수가 직접 장전(×2.5).
T-34/76 은 전차장이 포수를 겸하므로 탐지 배율이 0.75 로 낮다.

### 탄종별 거리-평균 관통력 (수직 0° 환산, mm)
원자료는 "30° 경사판" 기준 표(Wikipedia 등 공개자료)이며 1/cos30° 로 환산했다. ≈ 는 문헌 편차가 큰 근사값.

| 포 · 탄 | 종류 | 100m | 500m | 1000m | 1500m | 2000m |
|---|---|---|---|---|---|---|
| 8.8cm KwK 36 · PzGr.39 | APCBC-HE | 139 | 127 | 115 | 105 | 97 |
| 8.8cm KwK 36 · PzGr.40 ≈ | APCR | 197 | 180 | 159 | 141 | 122 |
| 8.8cm KwK 36 · Sprgr. L/4.5 | HE (작약 900g) | 17 | 17 | 17 | 17 | 17 |
| 75mm M3 · M61 | APCBC-HE | 83 | 76 | 69 | 64 | 58 |
| 75mm M3 · M72 ≈ | AP(고체) | 95 | 85 | 72 | 59 | 50 |
| 75mm M3 · M48 | HE (작약 670g) | 14 | 14 | 14 | 14 | 14 |
| 76.2mm F-34 · BR-350A | APHE | 77 | 70 | 64 | 58 | 52 |
| 76.2mm F-34 · BR-350P ≈ | APCR (1943~) | 106 | 92 | 69 | 52 | 40 |
| 76.2mm F-34 · OF-350 | HE (작약 710g) | 14 | 14 | 14 | 14 | 14 |

- APCR/AP(무피모)는 피모 보정 0°, 도탄 임계각 65° → 경사장갑에 상대적으로 약함. 작약 없음 → 관통 후 파편 피해만.
- HE 는 도탄 없음. 장갑은 거의 못 뚫지만 외부 폭발로 궤도(60%)·포·선회링 손상, 얇은 장갑이면 내부 박리로 승무원 부상 가능.
- 시험장(`tanks/lab/`)에서 탄종·거리·각도를 바꿔 가며 직접 확인할 수 있다.

## 검증 결과 (모델이 재현하는 전술적 사실)

셔먼 75mm → 티거, 방위 = 티거 정면 기준 사수 위치 각도. 차체 **하단** 조준(하부 측면 60mm가 노출되는 높이):

| 거리 | 0° | 30° | 45° | 60° | 90° | 180° |
|---|---|---|---|---|---|---|
| 100m | 0% | 0% | 81% | 100% | 100% | 75% |
| 300m | 0% | 0% | 52% | 100% | 100% | 44% |
| 500m | 0% | 0% | 19% | 99% | 100% | 14% |
| 1000m | 0% | 0% | 0% | 77% | 100% | 0% |

- 정면(0~35°)에서는 셔먼·T-34 모두 **어떤 거리에서도 티거를 관통 못 함** → 티거는 정면을 적에게 향하고 비스듬히 서면 안전.
- 측면 60° 이상으로 돌아 들어가면 하부 측면이 거의 확실히 관통 → **연합군의 우회·측면 공격**이 학습해야 할 핵심.
- 티거 상부 측면(80mm)은 셔먼 기준 300m 47%, T-34 기준 300m 5% → 근접할수록 유리.
- 88mm는 2000m에서도 셔먼·T-34 정면을 관통(단 T-34 를 30° 비스듬히 보면 상부측면 40mm@40° 에 도탄 25%).

몬테카를로(무작위 명중점, 400회):

| 상황 | 10발 내 전투불능 | 평균 명중 수 |
|---|---|---|
| 셔먼 → 티거 300m 정면 / 35° | 0% / 0% | - |
| 셔먼 → 티거 300m 측면 | 96% | 2.7 |
| 셔먼 → 티거 300m 후면 | 96% | 3.2 |

## 다른 코드에서 쓰는 법

```gdscript
var spec := TankDatabase.get_spec("tiger1")
var state := TankDamageState.new(spec)

# 사격 1발: 표적 로컬 좌표의 탄 궤적
var inv := target_node.global_transform.affine_inverse()
var result := DamageModel.resolve_shot(state, target_turret_yaw,
		inv * muzzle_world, (inv.basis * dir_world).normalized(), distance_m, shooter_spec.gun, rng)
# result: zone, impact_angle_deg, effective_mm, pen_roll_mm, penetrated, damage[], events[], status_after ...

# 성능 배율 (조작/전투 코드에서 사용)
state.can_move(); state.can_fire(); state.reload_time_s(); state.traverse_rate_deg_s()
state.track_efficiency("left"); state.spotting_multiplier()

# AI 관측 / 사고 기록
state.observation()          # PackedFloat32Array, 라벨: TankDamageState.OBSERVATION_LABELS
Ballistics.penetration_probability(gun, dist, plate_mm, angle)  # "지금 쏘면 뚫릴 확률" 피처
state.to_dict()              # 로그용 전체 상태
```

## 가정과 한계 (보고서에 명시할 것)

- 형상은 상자 두 개. 포방순·관측창·기관총 볼마운트 등 약점, 곡면 주조장갑은 대표 두께/경사로 평균화.
- 관통력은 공개 자료의 대표값이며 장갑 품질(독일 후기 장갑 저하, 소련 고경도 장갑 등)은 무시.
- 탄도 낙차·비행시간은 아직 없음(직사 광선). 분산은 포별 mrad 정규분포.
- 고폭탄, 포탑 링 쐐기, 승무원 숙련도는 미구현. 확률 계수(유폭·화재·탈출)는 `tank_database.gd`, `damage_model.gd` 상단 상수로 조정 가능.
- 근사치(≈)로 표시한 값(예: BR-350A 작약량, T-34 포탑 장갑)은 문헌별 편차가 크다.
