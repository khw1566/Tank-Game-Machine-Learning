# 전차 모델 (tanks/)

목표는 현실 제원을 그대로 옮기는 것이 아니라, **세 전차가 서로 다른 모델을 갖고 그 차이 때문에 서로 다른 전술이 나오게** 하는 것이다.
그래서 특성은 표에만 있는 것이 아니라 형상(피탄면적·경사), 조종/물리(기어·후진·지형 기울기), 사격(조준 오차·안정장치·탄도)에서 **강제**된다.
물리엔진 없이 해석적으로 계산하는 부분이 대부분이라 헤드리스 학습에서도 빠르고(전차 1대 1스텝 ≈ 0.1ms), 시드를 고정하면 재현된다.

## 전차별 특성 → 기대 전술

| | Tiger I | M4 Sherman (75) | T-34/76 |
|---|---|---|---|
| 형상 | 크고 각진 상자, 전고 2.82m, 정면 7.9m² | **높은 차체(지붕 1.95m)**, 전고 2.75m, 정면 5.8m² | **낮은 차체(지붕 1.65m)**, 전고 2.37m, 정면 5.1m² |
| 장갑 | 전면 100(거의 수직)·포방패 120, 측면 80/60 | 상부전면 51@56°, 측면 38 | **사방 경사**: 전면 45@60°, 측면 상부 40@40°, 후면 40@47° |
| 포 내림/올림 | −8° / +15° | **−10°** / +25° | **−5°** / +26° |
| 변속기(게임용 시간) | 프리셀렉터 전진 8 / 후진 4단, 변속 0.18s | 동기물림 5 / 1단, 변속 0.25s | 비동기 4 / 1단, 변속 0.40s(**2→3단 0.55s**) |
| 기어표 최고 전진 / 후진 | 45.4 / 9.2 km/h | 38.6 / **5.0** km/h | 51.1 / 7.3 km/h |
| 야지 최고(평지 / 5° / 10°) | 20.9 / 9.2 / 6.2 km/h (6단) | 25.4 / 9.1 / 3.7 (4단) | **27.1 / 16.4 / 7.8** (3단) |

| 조향 | 제자리 선회 가능 | 제자리 선회 불가 | 제자리 선회 불가, 효율 낮음 |
| 포탑 선회 | **6°/s** (90°에 15초) | 24°/s | 20°/s |
| 안정장치 | 없음 | **수직 1축** | 없음 |
| 정지 분산 / 조준 수렴 | **0.30 mrad** / 1.8s | 0.45 / 2.2s | 0.55 / **3.0s**(전차장 겸 포수) |
| 주행 중 조준 오차(최고속도) | 8.1 mrad | **3.5 mrad** | 14.7 mrad |
| 포구초속(1200m 낙차) | **773 m/s (11.8m)** | 619 (18.4m) | 662 (16.1m) |

- **티거**: 정면을 적에게 두고 30~45° 비스듬히(정면·측면 모두 불관통), 멀리서 멈춰 쏜다. 포탑이 느려서 측면으로 돌아오는 적은 차체를 돌려 대응해야 한다.
- **셔먼**: 능선 뒤에서 앞이 들린 자세(헐다운)로 포탑만 내밀고 쏘거나, 안정장치로 움직이며 쏜다. 75mm 로 티거 정면은 불가 → 측면을 잡는 동료를 엄호.
- **T-34**: 낮고 경사진 차체로 덜 맞고 튕겨내며 빠르게 우회해 측면으로 파고든다. 후진이 나빠 빠질 때는 차체를 돌려야 하고, 헐다운은 어렵다.

## 공통 모듈 구조 (모든 전차 동일)

`TankShape` 가 제원으로부터 볼록 다면체 부품을 만든다. 경사장갑은 **실제로 기울어진 면**이라 피탄면적·입사각·도탄이 형상에서 바로 나온다.

| 모듈 | 형상/구역 | 맞았을 때 |
|---|---|---|
| 1. 무한궤도 `track_left/right` | 차체 옆 하부를 덮는 상자 (zone `track`) | 75% 확률로 궤도 손상(파괴 시 기동불능). 철갑탄은 `track_armor_mm` 만큼 관통력이 깎인 채 차체 하부측면으로 진행 |
| 2. 포탑 | 장갑면 `turret_front/side/rear/top` + 내부 `turret_ring`(선회링), `traverse_drive`(선회장치), `sight`(조준경) | 선회장치 손상 50%, 파괴 시 수동 선회 15% · 조준경 손상 시 분산 ×1.6·조준시간 ×1.5 |
| 3. 포방패 `mantlet` | 포탑 정면 앞에 튀어나온 별도 장갑. 뒤에 `gun_mount`(고저장치) | 불관통이어도 12% 고저장치 손상(고저 속도 40%), 파괴 시 포 고착 + 안정장치 정지 |
| 4. 주퇴기·주포 | 내부 `recoil`(주퇴복좌기), `gun_breech`(포미), 외부 `gun_barrel`(포신 상자) | 주퇴기 손상: 재장전 ×1.5·분산 ×1.3, 파괴: 사격 불가 · 포신 명중: 손상(분산 ×2) 또는 40% 파괴 |
| 5. 차체 장갑 | `hull_front_upper/lower`, `hull_side_upper/lower`, `hull_rear`, `hull_top`, `hull_bottom` | 관통 시 파편 원뿔 + 작약 폭발로 승무원·모듈 피해 |

엔진·변속기·연료·탄약고·승무원 배치는 기존 모델 그대로(전차마다 위치가 다름).

## 조종·물리에서 강제되는 것 (`tank.gd`)

1. **차체 기울기(피치/롤)**: 궤도마다 앞·뒤 절반에서 4점씩(0.7m 간격) 지면을 재고 가장 높은 곳을 지지점으로 본다.
   지형 굴곡·잔굴곡(맵 `micro_relief_m`)과 `obstacle_step_m` 보다 낮은 돌·통나무를 타면 그쪽 궤도가 들려 차체가 기운다.
   더 높은 턱은 궤도 앞끝 탐침(`_step_blocked`)이 막는다(0.7m 돌: 티거·T-34 넘음, 셔먼 막힘).
   실제 자세는 현가 스프링-감쇠 모델(`suspension_freq_hz`, `suspension_damping`)로 이 목표를 따라가며,
   가감속하면 앞뒤로(`suspension_pitch_deg_per_mps2`), 선회하면 바깥으로(`suspension_roll_deg_per_mps2`) 쏠린다.
2. **포 각도 재조정**: 포 고저각·포탑 각은 차체 기준이다. 앞이 7° 들린 자세에서 같은 높이 적을 겨누려면 포를 −6.6° 내려야 한다
   → **T-34(−5°)는 불가, 셔먼·티거 가능**. 9° 면 셔먼만 가능. 옆으로 10° 기울면 같은 높이의 좌/우 45° 표적에 포 고저각이 ±7° 씩 달라진다.
   기운 차체에서 포탑을 오르막 쪽으로 돌리면 `traverse_slope_penalty` 만큼 느려진다(티거 90°: 12s ↔ 21s).
   `gun_world_limits_deg()` = 지금 자세에서 겨눌 수 있는 월드 고저각 범위(관측에도 포함).
3. **변속기**: 기어표(`forward_gears_kmh`, `reverse_gears_kmh`)는 실제 변속기의 기어별 속도. 견인력 = 엔진출력×0.6 / 그 단 최고속도
   (접지 마찰 0.6×중량 상한), 저항 = 중량×(구름저항 + sin경사), 구름저항 = 0.045 + 0.025×접지압. 조종수 자동 변속:
   단 최고속도 근처에서 다음 단이 저항을 이기고 변속 중(동력 단절, `shift_time_s`) 속도를 너무 잃지 않을 때만 올리고,
   저항을 못 이기면 내린다. 그래서 야지 최고속도·오르막 속도가 출력중량비·기어 간격·접지압에서 나온다(T-34 는 4단을 못 씀).
   양의 순가속에는 게임용 `acceleration_scale=4`를 적용한다. 저항을 이기는 기어와 최고속도 제한은 유지한다.
   엔진 응답은 0.20~0.25초로 짧게 하고, 변속 중에는 클러치만 끊어 엔진 회전을 유지한다.
   변속 뒤 매번 출력이 0부터 다시 올라가던 지연을 없앴다. 전진 중 후진 명령 → 멈춘 뒤 `direction_change_s` 동안 전환.
   궤도 명령 1.0 = 그 방향 기어표 최고속도(낼 수 있는 만큼), 0.5 = 절반 속도 목표.
4. **조향**: 선회율 = 궤도 속도차 / 궤도 간격 × `steer_efficiency`. 제자리 선회 불가 전차는 반대 궤도가 멈추기만 한다.
5. **충돌**: 바위·나무·전차와는 수평으로만 충돌·미끄러짐. 높이는 지면 표본으로 맞춘다(헤드리스에서도 결정적).

## 사격에서 강제되는 것

- **조준 오차**(`aim_error_mrad`, 분산 1σ): 목표값 = 정지 분산 × 손상배율 + 안정장치배율 × (이동 속도·차체 흔들림) + 차체 선회 + 포탑 선회.
  커질 때는 즉시, 줄어들 때는 `aim_time_s` 시상수로 지수 감소. 발사하면 다시 2배 정지 분산으로 튄다. 발사 방향은 이 값으로 흩어진다.
- **수직 안정장치**(셔먼): 차체 피치 변화의 85% 를 포가 반대로 보정해 월드 고저각을 유지(요철 주행 시 포 흔들림 0.26° vs 1.5°), 이동·흔들림 오차 ×0.35.
- **포물선 탄도**: 포구초속으로 0.1초 간격 적분, 구간마다 지형(물리 레이)과 모든 전차(해석적 형상) 교차. 관통력 거리는 실제 비행거리.
  `Tank.aim_solution(world_point)` 가 낙차를 보정한 포탑·포 각도와 `reachable`(고저 한계 안인가)을 준다(스크립트 AI·테스트용).
- **도탄**: 입사각이 (임계각 − 18°) 부터 서서히 오르고 (임계각 + 5°) 에서 확실. 판이 구경보다 얇으면(과구경) 덜 튕긴다.
  → 88mm 로 30° 비스듬히 쏘면 T-34 전면 도탄 32%, 셔먼 22%. 75mm 로 T-34 전면을 30° 에서 쏘면 37%.

## 판정 절차 (사격 1발, `DamageModel.resolve_shot`)

1. **명중 부위**: 표적 로컬 좌표의 탄 궤적을 부품(차체·궤도·포탑·포방패·포신)과 교차시켜 가장 먼저 맞는 면.
2. **궤도**: 궤도 손상 판정 후 관통력 −`track_armor_mm`, 궤도를 빼고 다시 추적(차체 하부측면).
3. **포신**: 장갑 판정 없이 포신 손상/파괴.
4. **입사각** = 실제 면 법선과 탄 방향의 각, **유효장갑** = 두께 / cos(입사각 − 피모 보정).
5. **도탄** → **관통력 굴림**(평균 × (1 + N(0, 5%))) → 관통이면 파편 원뿔·작약 폭발로 내부 피해, 유폭·화재·탈출 판정.
6. **비관통 효과**: 하부 명중 시 궤도, 포방패 충격(고저장치·주퇴기), 포탑 충격(선회링·선회장치·조준경).
7. **무력화**: 유폭, 화재, 탈출, 생존 1명 이하, 사격·기동 모두 불가.

## 검증 결과 요약 (테스트 출력에서)

셔먼 75mm → 티거, 차체 하단 조준(궤도 너머 하부측면 60mm, 궤도가 15mm 흡수), 방위 = 티거 정면 기준 사수 각도:

| 거리 | 0° | 30° | 45° | 60° | 75° | 90° | 180° |
|---|---|---|---|---|---|---|---|
| 100m | 0% | 0% | 0% | 66% | 98% | 99% | 49% |
| 300m | 0% | 0% | 0% | 26% | 86% | 93% | 19% |
| 500m | 0% | 0% | 0% | 4% | 51% | 65% | 3% |
| 1000m | 0% | 0% | 0% | 0% | 1% | 2% | 0% |

- 정면~45° 에서는 연합군이 티거를 관통할 수 없다 → 티거는 정면을 향하고 비스듬히 서면 안전. 연합군은 60° 이상 측면, 가까이로 들어가야 한다.
- T-34 76mm 는 티거 하부측면도 100m 이내가 되어야 의미 있음 → T-34 는 더 깊이 파고드는 기동이 필요.
- 88mm 는 2000m 에서도 셔먼(93%)·T-34(83%) 정면을 관통, 나머지는 도탄. T-34 는 경사 덕에 덜 관통된다.

몬테카를로(무작위 명중점, 400회): 셔먼 → 티거 300m 정면/35° 0%, 측면 96%(평균 2.8발), 후면 87% · T-34 → 티거 300m 측면 76% · 티거 → 셔먼 1000m 정면 100%(1.9발), → T-34 100%(2.2발).

## 다른 코드에서 쓰는 법

```gdscript
var t := Tank.new(); t.setup("t34_76", 1, seed); t.position = p; t.rotation.y = yaw; add_child(t)
t.control = TankControlInput.from_array([left, right, brake, traverse, elevation, fire])
t.step(1.0 / 30.0)                   # 학습 루프에서 직접 호출 가능(delta 를 그대로 사용)

t.observation()                      # 기동·사격 관측(Tank.OBSERVATION_LABELS)
t.damage.observation()               # 피해 관측(TankDamageState.OBSERVATION_LABELS)
t.aim_solution(enemy_point)          # {turret_yaw, gun_pitch, reachable, superelevation_deg, range_m}
t.aim_error_mrad; t.gear; t.hull_pitch_deg()
t.state_dict()                       # 로그용 전체 상태
Ballistics.penetration_probability(gun, dist, plate_mm, angle)
```

## 가정과 한계 (보고서에 명시할 것)

- 형상은 볼록 다면체 6개(차체, 궤도 2, 포탑, 포방패, 포신). 곡면 주조장갑·관측창·기관총 마운트는 대표 경사로 평균화.
- 기어별 속도는 실제 자료: 티거 3000rpm 기어표(Tiger I Information Center), 셔먼 기어비 7.56/3.11/1.78/1.11/0.73·R5.65 를 2400rpm 24mph 로 환산,
  T-34 교범의 1700rpm 계산값(7.4/15.45/25.6/48.3, R6.9)을 1800rpm 으로 환산. 변속 시간·현가 계수·구름저항·조준 수치는 특성 대비용 게임 값.
- 고증상 후진은 셔먼(1단 5.0km/h)이 가장 느리다. T-34 의 "나쁜 후진"은 전후진 전환 3.0s 로 표현된다.
- 공기저항 없음(낙차는 포구초속만으로 결정), 비행시간은 결과에 기록하지만 명중은 발사 순간에 판정.
- 현가는 피치·롤 각각 1자유도 스프링-감쇠(상하 운동·보기륜 개별 운동 없음). 지지점은 궤도 반쪽의 최고점으로 근사.
- 조향 시 미끄럼 저항(선회 중 출력 손실)은 아직 없음.
- 관통력은 공개 자료 대표값, 장갑 품질 차이 무시. 확률 계수는 각 파일 상단 상수로 조정 가능.
