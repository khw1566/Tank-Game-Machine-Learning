# 주행 보상·wall 학습 수정 — 2026-11-17

첨부 영상·화면과 현재 v4.1 코드, `V4RUN-1` 기록을 확인했다.
기존 모델의 정책을 유지하면서 보상·성공 판정·세부 항목 선택·장애물 관측을 수정했다.

## 원인과 수정

- 주행 성공은 도착·정지만 검사해 후진으로도 통과했다. 기초 주행과 경로 선택에서 실제 이동 변위를
  차체 전방에 투영해 전후진 거리를 기록한다. 후진 m당 −0.08, 후진 진행 보상 없음,
  기동 여유 2m를 제외한 전진 비율 85% 이상을 성공 조건에 추가했다. 전투 중 후퇴는 허용한다.
- 변형과 전차를 독립적으로 무작위 선택해 통과 조합도 계속 실행했다.
  이제 변형 × 전차의 최근 40판 80%와 최소 판수를 충족하면 통과를 저장하고 선택에서 제외한다.
  병렬 환경에서 이미 시작한 판의 늦은 결과는 통과를 취소하지 않는다.
- 주변 엄폐 관측은 60m 범위에 45도 간격 단일 광선이었다. 120m 범위, 방위당 부채꼴 5개 광선으로 바꿨다.
  광선이 장애물 안에서 시작할 때도 감지한다. 입력 개수와 순서는 유지한다.
- 목표까지의 직선거리만 보상해서 벽 옆으로 이동하는 우회 행동의 진행도가 드러나지 않았다.
  전차 크기·회전된 장애물 외곽을 반영하는 경로 거리로 보상을 계산한다. 경로는 정책에 전달하지 않는다.
  새 최단 진행도만 보상하므로 왕복으로 중복 획득할 수 없다.
- 오래 막힌 주행 과제는 보조 보상이 판수 때문에 0이 됐다. 미통과 주행 과제는 최소 0.2 배율을 유지한다.

상세 규칙과 버전: [CURRICULUM_V4.md](../training/CURRICULUM_V4.md).

## 검증

- Python 테스트 41개 통과.
- 기존 지형 검사 5,980개와 새 주행·관측 검사 38개 통과.
- 새 검사에는 세 전차의 후진 도착 실패, 전진 도착 성공, 기존 광선 사이의 사각지대,
  60m 밖 벽 감지, 우회 보상, 왕복 보상 방지가 포함된다.
- 실제 물리 주행에서 티거·셔먼·T-34 모두 벽 우회와 엇갈린 통로를 전진으로 완주했다.
  벽 코스는 목표 반대 방향으로 출발해 선회 후 주행했으며 후진 거리는 모두 0m였다.
  이 결과는 검증용 경로 제어기의 결과이며 학습 정책의 습득 성과가 아니다.
- 27개 세부 상황의 원본 실행과 재현 종료 해시가 모두 일치했다.
- 배포용 EXE에서 wall 에피소드의 종료 해시가 에디터 실행과 일치했다.
- 기존 모델을 새 EXE에 불러와 CPU 추론·GPU PPO 갱신 128스텝 검증을 마쳤다.

## 현재 실행과 보존

교체 전 실행 파일과 모델·커리큘럼·체크포인트 정보는
`build/backups/20261117_driving_v2_before/`에 보관했다.
검증 로그와 재현 결과는 `build/validation/driving_v2_*`에 있다.

`build/TankGame.exe`를 교체하고, 기존 **20,610,904스텝** 체크포인트에서
`V4RUN-1`의 100환경·hybrid 학습을 재개했다. 기존 총 목표 스텝도 유지했다.
예전 성공률에는 후진 통과가 섞여 있어 모델·optimizer·누적 스텝은 유지하고,
평가만 `m1_drive`부터 다시 시작한다. 이전 평가는 `previous_assessments`에 보관된다.
재평가 변경은 `curriculum_log.jsonl`에 `assessment_upgrade`로 기록된다.

이 수정으로 wall을 학습할 수 있는 관측·보상과 물리적 통과 가능성을 검증했다.
학습 정책의 wall 성공률 개선은 이후 재학습 결과로 확인해야 한다.
