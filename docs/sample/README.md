# README에 사용한 실제 출력 자료

루트 [README](../../README.md)의 화면과 경기 통계에 사용한 자료다.

| 파일 | 출처와 범위 |
|---|---|
| `screen_game_overlay.png` | 기존 게임 실행 캡처. 화면에 ep5, 전원 AI 관전 상태가 표시된다. |
| `screen_replay_chase.png`, `screen_replay_gunner.png`, `screen_replay_orbit.png`, `screen_replay_top.png` | 기존 리플레이 캡처. 화면에 `ep0004_2026-11-16_08-30-14`가 표시된다. |
| `sample_report_tiger_win.html` | 기존 실제 경기 HTML. 기록 시각 `2026-11-16T08:16:17`, 맵 시드 2, 4분 32초, 티거 1 vs 연합군 3. |
| `screen_report_summary.png` | 2026-11-17에 위 HTML을 Chromium에서 1280×1000으로 캡처한 첫 화면. 결과·전차별 표·동선 일부를 표시한다. |

게임·리플레이 캡처는 HTML 보고서와 다른 경기 자료다. 자료의 원본 생성 시각·시간대·코드 커밋은
파일명과 화면·보고서에 표시된 범위에서만 확인할 수 있다. 현재 코드로 새로 실행한 화면이라고 해석하지 않는다.
보고서 캡처를 만들 때 HTML 원본은 수정하지 않았다.

HTML 원본 SHA-256:

```text
c41c200678750eee30a38bfaa657c9b19e516b47f6864ba2658601709edde1c4
```

HTML을 로컬 브라우저로 열면 전체 지도, 체류 히트맵, 점수 그래프, 피탄 분석, 전체 사격 표를 읽을 수 있다.
GitHub의 HTML 파일 페이지에서는 소스가 표시된다. 그림만 보려면 루트 README의 PNG를 확인한다.

보고서의 누적 5경기 승패 그래프는 현재 경기의 승리 머리말과 일치하지 않는다.
루트 README는 현재 경기 머리말·전차별 요약·사격 표를 근거로 수치를 기록했다.
이 자료에는 학습 정책 성능을 검증하는 평가 실행이나 체크포인트 식별 정보가 없으므로 학습 완료의 증거로 쓰지 않는다.
