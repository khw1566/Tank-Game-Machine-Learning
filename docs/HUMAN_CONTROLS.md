# 사람 조종 · 궤도 표시 · 탄착 카메라

## 마우스 조준

| 입력 | 동작 |
|---|---|
| 커서 이동 | 3인칭에서 커서가 가리키는 지점으로 포탑·포 고저를 조절 |
| 좌클릭 또는 F / Enter | 발사 |
| 우클릭 또는 C 누르기 | 포를 고정하고 카메라만 둘러보기 |
| Shift | 포수 조준경 전환. 마우스 이동으로 포탑·고저각을 조절 |
| 휠 / + / − | 조준경 배율 조절 |
| B | 전차장 시점. 포는 고정 |
| R | 마우스 조준 켜기/끄기 |
| 방향키 | 키보드로 포탑·포 고저 조절. 누르는 동안 마우스 조준보다 우선 |
| F8 | 상세 HUD 켜기/끄기 |

궤도 주행 입력은 기존과 같다: Q/A 좌측, E/D 우측, W/S 양쪽, Space 브레이크.
3인칭 조준 카메라는 포탑 회전에 끌려가지 않는다. 우클릭/C로 시야를 바꾸고 놓으면 새 시야를 유지한다.
3인칭은 커서 지점에 대한 탄도 낙차를 보정하고, 포수 조준경에서는 마우스로 각도를 직접 조절한다.
포탑 선회·고저 속도, 포의 각도 제한과 손상 효과는 기존 제원을 그대로 따른다.

## 궤도와 피격 표시

궤도 바깥에 트레드 링크·바퀴·허브를 표시한다. 트레드는 좌우 실제 궤도 속도로 각각 순환하며,
후진하면 반대로 움직인다. 손상된 궤도는 주황색, 파괴된 궤도는 붉게 표시하고 파괴된 쪽의 트레드는 멈춘다.
탄착은 작은 중심점과 색상 고리로 표시하며, 전차가 움직이거나 포탑을 돌려도 맞은 부위를 따라간다.
H로 전장 탄착 표시를 켜고 끈다. 최근 표시 128개를 유지하며 기록 파일에는 모든 사격을 남긴다.

## 미니맵 아래 탄착 창

현재 조종 전차가 쏘거나 현재 전차가 맞으면 미니맵 아래에 탄착 창을 연다.
포탄이 들어온 방향으로 약 0.9초간 접근한 뒤 명중 지점 가까이에서 화면을 유지한다.
명중 지점·장갑 부위·좌우 궤도·관통/불관통/도탄 결과를 표시한다. 다음 탄착 때 새 장면으로 바뀐다.

이 창은 실제 명중 좌표와 당시 전차 자세로 만든 시각적 스냅샷이다.
포탄 비행을 따라가는 연출은 충돌 판정 이후에 재생되며, 게임 진행을 멈추거나 판정을 다시 계산하지 않는다.
지형·장애물 탄착은 전차 복제 없이 탄착점을 표시한다. 빗나가서 탄착 좌표가 없는 사격은 이전 화면을 유지한다.

시각 효과는 헤드리스 학습에 생성하지 않는다. AI 관측 389개·행동 11개와 학습 체크포인트 형식은 유지한다.

## 검증

`controls/tests/run_human_ui_tests.gd`에서 실제 Intel OpenGL 렌더러로 19개 검사를 통과했다.
커서·저상 궤도 선택, 조준 속도 제한, 포수 입력, 자유 시선 잠금, 좌우 트레드,
실제 궤도 피격, 탄착 창 격리, 확대 이동, 미니맵 하단 배치와 이동 표적의 탄착 추적을 확인했다.
기존 시점 검사와 주행·선회·사격 스모크 테스트도 통과했다.
