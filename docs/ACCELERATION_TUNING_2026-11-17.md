# 가속·변속 응답 개선

2026-11-17. `build/TankGame.exe`에 반영 완료.

## 변경

- 양의 순가속에 게임용 배율 `TankSpec.acceleration_scale = 4.0` 적용.
- 변속 중에는 클러치가 구동력을 차단하되 엔진 출력 준비 상태를 유지해, 매 변속 후 다시 출력이 올라오던 지연 제거.
- 엔진 응답 시간: 티거 1.2→0.25초, 셔먼 0.8→0.22초, T-34 0.9→0.20초.
- 변속 시간: 티거 0.60→0.18초, 셔먼 1.00→0.25초, T-34 2.00→0.40초. T-34 2→3단은 3.00→0.55초.
- 기어별 최고속도·후진 속도·전후진 전환 시간·제동력·등판 가능 기어는 기존 설정 유지.

## 평지 실측

Godot 4.3, 물리 30Hz, 정상 전차, 양쪽 궤도 전진 100%, 브레이크 0.
도달 시간은 정지에서 **평지 야지 최고속도의 95%**까지 측정했다.

| 전차 | 평지 야지 최고속도 | 기존 95% 도달 | 변경 후 95% 도달 | 기존 0→10km/h | 변경 후 0→10km/h |
|---|---:|---:|---:|---:|---:|
| Tiger I | 20.9km/h | 28.07초 | 5.73초 | 8.33초 | 1.40초 |
| Sherman 75 | 25.4km/h | 34.73초 | 7.87초 | 5.63초 | 1.10초 |
| T-34/76 | 27.1km/h | 21.27초 | 4.60초 | 3.73초 | 1.03초 |

도로용 기어표 최고속도(45.4 / 38.6 / 51.1km/h)와 야지에서 낼 수 있는 최고속도는 기존처럼 구분한다.
이번 변경은 가속 응답을 빠르게 조정한 것이다.

## 검증

- 가속·자동 변속·최고속도 제한·후진·제동·파손 궤도 구동 제한: **33개 검사 통과**.
- 기존 기동·현가·조향·사격 특성 검사: **46개 통과**. 기존의 느린 가속 기대값을 새 목표로 변경.
- 장갑·피해·모듈 검사: **47개 통과**.
- 새 EXE 자체에서 가속 검사 33개 재검증 및 이동·선회·사격 통합 검사 통과.
- 새 EXE의 학습 에피소드 기록→재현: 움직이는 표적 / 1대1 / 팀전 **3개 모두 final_hash 일치**.
- 본 학습은 시작하지 않았다. 기존 학습 체크포인트를 변경하지 않았다.

물리가 바뀌었으므로 과거 버전에서 기록한 에피소드의 재현 해시는 달라질 수 있다.
새 코드로 기록한 에피소드의 재현 일치 여부를 별도로 검증했다.

## 파일

- `tanks/tank.gd`: 스로틀 유지·클러치 차단·가속 배율 적용.
- `tanks/tank_spec.gd`, `tanks/tank_database.gd`: 배율과 전차별 응답 설정.
- `tanks/data/tank_specs.json`, `tanks/README.md`: 갱신된 제원·안내.
- `tanks/tests/run_acceleration_tests.gd`: 가속 회귀 검사.
- `build/validation/`: 변경 전후 측정·검증·내보내기 로그.
- `build/backups/TankGame_before_acceleration_20261117.exe`: 교체 전 실행 파일 백업.

학습·게임 실행에는 기존과 같은 `build/TankGame.exe` 경로를 사용하면 된다.
