# 빠른 교전 보상 v3

10단계 소형 전장의 7개 독립 개체에 적용한다. 모델 가중치·optimizer·누적 스텝은 그대로 이어받는다.
보상 규칙이 다른 과거 v2 기록은 수정하지 않고, 그래프에서는 v2와 v3를 분리한다.

|행동·결과|보상|
|---|---|
|살아 있는 적 명중, 불관통 포함|+5|
|관통|명중에 추가 +3|
|격파|명중·관통 등에 추가 +12|
|지근탄|적 중심 12m 이내의 실제 탄도에 최대 +1, 더 가까워진 정도만 지급|
|적과의 거리 단축|스스로 새로 단축한 거리 1m당 +0.03, 경기당 최대 +4|
|처음 150m / 100m / 60m / 30m 안으로 접근|각각 +0.5 / +0.75 / +1 / +1.5|
|새 적 탐지|+0.3|
|발사했지만 명중하지 않음|−0.05, 지근탄 보너스와 별도 계산|
|살아 있는 동안 시간 비용|초당 −0.02|
|시간 초과|생존 개체당 −4|
|승리 / 패배|+15 / −10|

승무원·모듈의 실제 피해 보상은 기존 규칙대로 추가된다.
아군 명중은 감점이며, 잔해 명중에는 명중·관통·격파 보너스를 주지 않는다.

지근탄은 첫 충돌 이전의 실제 포물선 구간에서 측정한다. 담장이나 아군에 막힌 구간 너머의 적은 인정하지 않는다.
20m 미만의 지근탄에는 보너스를 주지 않아 발밑 사격을 막는다. 실제 근거리 명중은 정상적으로 +5를 받는다.
동일한 적에 대한 지근탄은 이전보다 가까워진 만큼만 보상하고, 전체 지근탄 보너스는 개체당 경기 최대 +3이다.
예를 들어 첫 3m 지근탄은 +0.75에서 발사 비용 0.05를 뺀 +0.70이다. 같은 거리에 반복 사격하면 추가 보너스가 없다.

거리 단축은 자기 이동 중 적 쪽으로 전진한 몫만 인정한다. 제자리에서 적이 다가오는 것과 왕복 이동은 보상하지 않는다.
25m보다 가까이 붙는 이동에는 추가 거리 단축 점수가 없으며, 거리별 진입 보너스는 개체마다 경기당 한 번만 지급한다.

에피소드 결과의 `combat_rewards`와 개체별 `reward_components`에 보상 내역을 저장한다.
학습 보고서에는 구성 합계를 표시하며, 경기 리플레이의 점수도 이 실제 훈련 보상을 그대로 사용한다.
명중·관통·지근탄·접근·승패 점수를 기록기에서 다시 중복 합산하지 않는다.

새 가중치가 전투 능력을 개선했는지는 충분한 학습과 같은 시드의 고정 모델 평가로 따로 확인한다.
