# V7 Godot 플레이와 행동 복제

셔먼 75나 T-34 76 한 대를 직접 운전해 차종별 시범을 모은다. 플레이어와 PPO는 모두 같은 Godot 3D 씬, 전차 주행 물리, 관측, 조작을 사용한다. 사람이 플레이할 때는 게임 창에 지형과 전차가 보이고, PPO가 플레이할 때는 같은 씬을 헤드리스로 실행한다.

## 게임 창에서 시범 수집

1. [Play_V7.bat](Play_V7.bat)를 실행하거나 학습 대시보드의 **Godot에서 시범 플레이**를 누른다. 두 방법 모두 `TankGame_v6.exe`를 창 모드로 연다.
2. Godot에서 **셔먼 75** 또는 **T-34 76**, 경기 인원과 학습 맵을 고르고 **경기 시작**을 누른다. 1대3이라면 내가 연합 전차 한 대를 조종하고 게임이 아군 두 대와 상대 한 대를 조종한다. **학습 맵 무작위**를 선택하면 PPO와 같은 규칙으로 맵과 배치를 뽑는다. 같은 차종·인원에서 화면에 표시된 **경기 시드**로 배치를 재현할 수 있다.
3. **W/S**로 전후진한다. **Q/A**는 왼쪽 궤도, **E/D**는 오른쪽 궤도, **Space**는 제동이다. 마우스는 3인칭 카메라를 움직인다. 포탑과 링 커서는 화면 중앙에 들어오는 지형이나 링 표식의 위치를 따라간다. 보라색 체크포인트를 통과한 뒤 **좌클릭**, **F** 또는 **Enter**로 열린 링을 태그한다.
4. **Shift**는 포수 시점, **B**는 전차장 시점이다. 3인칭에서 **우클릭**이나 **C**를 누르고 있으면 카메라만 돌아가고, 놓으면 조준하던 방향으로 돌아온다. 휠로 포수·전차장 배율을 바꾼다. 붉은 선은 학습 관측에도 보이는 상대를 가리킨다.
5. 첫 입력부터 0.1초마다 기록한다. 잠시 손을 놓는 행동도 시범에 들어간다. **P** 또는 **Esc**로 일시정지한다.
6. 경기 종료 시 결과, 저장된 조작 수, 파일 경로가 Godot 화면에 나온다. **시범 폴더**에서 파일을 확인하고 **새 경기**로 이어갈 수 있다.

포탄을 발사하려면 **일반 전투**를 누른다. 선택한 연합 전차로 기본 게임이 열리며 **좌클릭** 또는 **F**로 발사한다. 일반 전투에서 **F9**를 누르면 시범 수집으로 돌아올 수 있다.

## 모은 시범으로 학습

대시보드에서 준비된 **V7-Godot-3**을 선택하고 **새 학습 / 이어서**에서 학습 차종을 고른다. **사람 시범으로 초기 행동 학습**을 켜고 시작하면 해당 차종의 첫 PPO 업데이트 전에 행동 복제를 수행한다. 셔먼으로 한 판을 끝냈다면 셔먼만 먼저 학습할 수 있다. 세 차종 교대와 행동 복제를 함께 선택하려면 셔먼과 T-34 각각의 시범이 필요하다. 티거는 독립적으로 무작위 초기화한 정책에서 시작한다.

Godot이 저장하는 경기별 JSON에는 차종, 인원, 맵, 원본 배치 시드, 배치 ID, 종료 결과와 함께 **관측 78개**와 포탑 좌우·상하를 포함한 **행동 9개**가 순서대로 들어간다. 한 행동은 30Hz 물리 3틱 동안 적용된다. 기본 경로는 `%LOCALAPPDATA%\TankGameML\training\v7_godot_control_demos\<차종>`이다. 포탑 입력을 학습하려면 이 버전으로 경기 시범을 수집한다.

학습기는 경기 시드로 맵과 배치 ID를 확인한 뒤 입력 규격과 완료 상태가 일치하는 시범을 읽는다. 경기 두 판 이상이면 한 판 이상을 통째로 검증에 사용한다. `<실행>/<차종>/curriculum.json`의 `behavior_clone`에 파일 해시, 학습·검증 표본 수와 행동 오차가 남는다. 같은 실행을 재개하면 보정한 정책과 PPO 상태를 이어간다.

프로젝트 루트에서 아래 명령으로 게임 창을 직접 열 수 있다.

```powershell
.\training\Play_V7.bat
```

이미 준비된 실행에 셔먼 시범을 적용하는 명령은 다음과 같다.

```powershell
py -3.14 training/python/train_v7.py --run V7-Godot-3 --resume --tank sherman75 --behavior-clone
```

## 커리큘럼

구릉과 숲, 중앙 능선, 마을, 계곡, 바위 지대의 원본 V6 맵 설정을 사용한다. 1대1·1대2·1대3·1대6 단계별로 V6 생성기가 만든 차종별 배치 16개씩을 각 맵에 넣었다. 총 960개 배치를 Godot 빌드에 포함한다. V6와 V7은 지형과 장애물 생성, 스폰 좌표 보정에 같은 Godot 함수를 사용한다. 링 태그와 측면 체크포인트 튜토리얼은 1대1 맵을 바탕으로 한다.

기존 생성기를 수정한 뒤 V7 배치 파일을 갱신하려면 프로젝트 루트에서 `py -3.14 training/python/build_v7_layouts.py`를 실행하고 게임을 다시 내보낸다.

| 단계 | 목표 | 승급에 필요한 최근 64경기 성공률 |
|---|---|---|
| 링 태그 | 링 3개 태그 | 75% |
| 측면 체크포인트 | 좌우 체크포인트를 거쳐 링 3개 태그 | 70% |
| 1대1 | 링 3개 경주 | 60% |
| 1대2 | 링 4개와 연합 릴레이 | 60% |
| 1대3 | 링 5개와 연합 릴레이 | 55% |
| 1대6 | 링 6개와 연합 릴레이 | 최종 단계 |

체크포인트 통과는 **+4**, 링 태그는 **+1**이다. 시야 안에 라이벌의 옆면 표식이 나타나면 태그 없이도 **+0.5**를 받으며, 경기당 같은 상대에게 한 번 적용된다. 티거의 가상 방패는 펄스 방어 **+0.15**, 반사 **+0.35**이며 합계는 한 경기 **+0.90**까지다.

측면 체크포인트는 **4분**, 1대1·1대2·1대3·1대6은 각각 **5·6·7·8분**이다. 상대가 먼저 점수를 얻더라도 제한 시간의 80%가 지나야 마지막 점수가 반영된다. 이 시간과 판정은 사람의 시범 경기와 PPO에 똑같이 적용된다.
