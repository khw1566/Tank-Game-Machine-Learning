# 10단계: 독립 개체 1 대 6 · 소형 전장

티거 I 1대 대 셔먼 75mm 3대 + T-34/76 3대의 전투다.
맵은 **360×360m**, 진영 기준 시작 거리는 **200m**, 제한 시간은 **180초**다.
이전 1200m 맵·900m 출발·600초 시험과 다른 v2 과제로 기록한다.
중앙 사격로와 스폰 구역을 비우고, 측면 바위·파괴 가능한 나무와 외곽 경계를 배치한다.
한 팀이 전투불능이면 상대 팀 승리, 시간 초과는 무승부다.

현재 학습에는 [빠른 교전 보상 v3](COMBAT_REWARDS.md)를 사용한다. 불관통을 포함한 명중 +5,
관통 추가 +3, 격파 추가 +12와 지근탄·거리 단축·근접 보상을 적용한다.

## 개체마다 별도 모델과 학습

|개체 ID|차종|
|---|---|
|`tiger1_0`|티거 I|
|`sherman75_1`, `sherman75_2`, `sherman75_3`|각각 별도의 셔먼|
|`t34_76_4`, `t34_76_5`, `t34_76_6`|각각 별도의 T-34|

7개체의 정책 가중치·옵티마이저·롤아웃 버퍼·누적 스텝·체크포인트는 모두 분리한다.
같은 셔먼이라도 다른 개체의 경험으로 자기 모델을 갱신하지 않는다.
한 전장에서 행동을 함께 수집한 뒤 각 모델은 **자기 관측·행동·보상**으로 PPO를 따로 갱신한다(IPPO).
격파된 개체의 유효 경험은 사망 시 끝내며, 남은 전투의 무의미한 행동을 학습 버퍼에 넣지 않는다.

기존 차종별 모델은 개체별 초기값으로만 복사한다. 기존 가중치·optimizer·누적 스텝을 이어받고 원본은 수정하지 않는다.
모델이 없는 개체는 서로 다른 시드의 새 정책을 만들며, 기본 대전에서 규칙 AI로 대체하지 않는다.
처음 같은 가중치로 출발한 셔먼도 별도 파라미터와 경험으로 학습하므로 이후 서로 달라진다.

## 독립 학습 실행

대시보드에서 원본 모델이 있는 실행을 선택하고 **7개체 독립 학습 / 이어서**를 누른다.
첫 실행은 별도 `independent_...` 실행에 모델을 초기화한다.
이후 그 독립 실행을 선택해 같은 버튼을 누르면 7개 모델을 각각 이어받는다.
저장·일시정지·재개·저장 후 중지 명령을 지원한다.

```powershell
cd training/python
.venv/Scripts/python.exe train_individuals.py --godot ../../build/TankGame.exe --source-run su1117_02 --run independent_su1117_02 --timesteps 10000
```

`--timesteps`는 공유 전장의 추가 결정 횟수다. 살아 있는 각 개체는 자기 유효 경험 수만큼 스텝이 증가한다.
사망 시점이 다르면 개체별 스텝 수도 다를 수 있다. `--n-steps` 기본값은 개체별 256이다.
기존 학습 경로에서 같은 차종에 정책을 공유하던 팀 학습은 차단한다. 다개체 최종전은 독립 학습 경로를 사용한다.

## 모델 고정 시험

독립 실행을 선택하고 **모델 고정 후 시험 시작**을 누른다. 기본값은 7개 독립 정책으로 1경기다.
각 모델의 저장된 복사본만 사용하며 학습·optimizer·누적 스텝을 갱신하지 않는다.
경기마다 새 Godot 프로세스를 사용해 이전 경기의 물리 상태를 제거한다.
선택 항목의 규칙 AI 비교는 명시적인 기준선이며, 독립 정책 학습과 구분한다.

```powershell
.venv/Scripts/python.exe evaluate.py --godot ../../build/TankGame.exe --source-run independent_su1117_02 --out "$env:LOCALAPPDATA/TankGameML/training/runs/evaluation_compact_001"
```

새 출력 폴더 이름을 사용한다. `--episodes 3 --modes mixed,scripted`로 같은 시드의 기준선 3판을 추가할 수 있다.
평가 시드는 기본 10001부터이며 현재 학습 맵 시드와 구분한다. 반복 사용한 시드는 새 미학습 시드로 세지 않는다.
관측 389개·행동 11개는 유지하며, 적 접촉 슬롯 4개·아군 슬롯 3개에는 우선순위가 높은 접촉을 담는다.

## 저장과 결과

- `agents/<개체 ID>/checkpoints/...`: 개체별 모델·커리큘럼·체크섬 저장 세대.
- `individuals.json`: 초기 모델 출처, 물려받은 스텝과 개체별 추가 학습량.
- `individual_progress.jsonl`: 각 개체의 경기별 보상·사격·관통·격파.
- 대시보드와 학습 보고서: 개체별 스텝·PPO 갱신·보상 곡선을 다른 색상으로 표시.
- `evaluation_report.html`, `evaluation.json`: 평가 방식별 결과와 개체별 모델 식별 정보.
- `episodes/env0/*.json`: 모든 경기의 설정·시드·행동·사격·동선.
- `env0/replays/ep.../events.jsonl`: 선택된 경기의 전체 리플레이. 나머지는 행동 기록으로 재현할 수 있다.

소수 경기나 짧은 초기 학습 결과만으로 전술 습득·일반 승률을 판단하지 않는다.
