# 세부 학습 목표별 그래프와 보고서

성공률·보상·에피소드 길이와 보고서 통계는 세부 목표별로 따로 계산한다.
각 목표에는 고정 색상과 범례가 있으며, 대시보드와 HTML 보고서가 같은 색상을 쓴다.
지형주행 코스는 기존 `terrain_progress.csv`와 에피소드 설정을 연결해 과거 기록도 분류한다.
규칙이 바뀐 v2·v3 코스는 다른 항목으로 구분한다. 목표가 기록되지 않은 자료는 `세부 목표 미기록`으로 표시한다.
원래 CSV·에피소드·모델은 수정하지 않는다.

사격 그래프도 목표별 색상을 쓰며, 명중률은 실선, 관통률은 점선으로 구분한다.
PPO 손실·엔트로피는 여러 목표가 섞인 학습 배치의 지표라 목표별 수치로 분해하지 않는다.
해당 그래프에는 혼합 배치 전체 지표임을 표시한다.

앞으로 새로운 세부 목표를 만들 때 단계 설정에 다음 정보를 추가한다.

```python
stage["learning_objective"] = {
    "id": "aim_left_track",
    "label": "왼쪽 궤도 조준",
    "version": 1,
}
```

설정은 에피소드 파일에 남고 그래프와 보고서에서 자동으로 별도 분류한다.
목표 의미나 판정 규칙을 바꾸면 `version`을 올려 이전 성적과 구분한다.
새 ID의 색상은 ID로부터 결정하므로 조회 순서·페이지 새로고침에 따라 바뀌지 않는다.
대시보드 파일을 갱신한 뒤 기존 브라우저 창은 새로고침한다.
