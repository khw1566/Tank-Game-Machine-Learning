# 지형주행 v2 · 안전 스폰 · 장애물 파괴

관측 389개와 행동 11개를 유지했다. 기존 정책과 optimizer를 그대로 불러오고,
새 과제의 성공률은 새로 측정한다. 기본 주행 복습에도 동일한 정지 규칙을 적용한다.

## 시험공간과 목표

시험장은 240×240m다. 매 에피소드 시드로 중심 위치·주행 방향·초기 차체 방향·거리·우회 방향·담장 개구부를 바꾼다.
시행 도중 장애물이 스스로 움직이지는 않는다. 전차나 포탄으로 파괴되기 전까지 배치를 유지한다.

| 코스 | 거리 | 과제 | 승급 기준 |
|---|---|---|---|
| `approach` 접근·정지 | 35~55m | 장애물 없는 목표점에 접근해 정지 | 최근 50판 85% |
| `detour` 단일 장애물 우회 | 55~75m | 좌우가 바뀌는 우회 목표점 순서대로 이동 | 75% |
| `gates` 개구부 통과 | 75~95m | 위치·폭이 바뀌는 담장 개구부 두 곳 통과 | 75% |
| `rough` 굴곡·낮은 장애물 | 60~85m | 구릉과 0.2~0.4m 장애물 극복 | 70% |
| `mixed` 복합 코스 | 90~120m | 우회·담장·굴곡 결합 | 70% |

모든 목표점에서 **5m 이내, 속도 1m/s 이하로 0.6초 유지**해야 한다.
중간 목표를 완료하면 다음 목표를 제시한다. 마지막 목표를 완료하면 성공이다.
완료한 이전 코스는 20% 확률로 복습한다. 최대 판수만으로 코스를 강제 승급하지 않는다.
코스별 최근 성적과 진행 상태를 체크포인트와 함께 저장한다.

## 보상과 종료

- 경로상 새로 달성한 최선의 진행도: 에피소드 전체 최대 +4. 되돌아갔다 다시 접근해도 중복 지급하지 않는다.
- 중간 목표 완료: 각 +1, 한 번만 지급한다.
- 마지막 목표에서 정지: +8.
- 시간: 초당 −0.02. 장애물에 2초 이상 계속 밀착해 구동하면 추가로 초당 −0.1.
- 20초 무진전, 구역 이탈, 기동불능, 제한 시간 초과: 실패, −2.

단순 직선거리 대신 우회 구간의 목표 순서를 기준으로 진행을 계산한다.
`terrain_progress.csv`와 에피소드 JSON에 코스·경로 거리·남은 거리·완료 목표 수·보상 항목을 기록한다.

## 안전 스폰

일반 경기와 학습에 공통 검사를 적용한다.

1. 실제 나무 줄기·담장·건물·바위 등 모든 충돌 형상을 검사한다.
2. 반경 5m의 빈 공간을 확보하고 숲·수목선·수관·생울타리 내부를 제외한다.
3. 차체 주변 경사 12° 이하, 높이 차 2.5m 이하를 확인한다.
4. 8방향 중 하나에 길이 18m, 반경 5m의 통로가 있어야 한다. 통로 경사는 18° 이하로 제한한다.
5. 다른 스폰과 12m 이상 거리를 유지한다. 후보를 찾지 못하면 명시적 오류로 종료하며 위험한 위치를 반환하지 않는다.

각 에피소드에 스폰 규칙 버전과 실제 스폰 위치를 저장한다.

## 파괴 가능한 장애물

나무, 돌담, 생울타리의 개별 구간은 전차의 충돌·지속적인 밀기 또는 포탄 직격으로 파괴된다.
게임 내 파괴 강도는 나무 25, 돌담 100, 생울타리 12의 kJ 환산값을 사용한다.
건물과 바위는 파괴되지 않는다.

파괴 시 해당 충돌체와 외형을 제거한다. 생울타리의 잎 차폐도 제거하고,
쓰러진 나무 주변 반경 3.5m에는 숲 차폐의 국소 통로를 만든다.
주변의 살아 있는 나무 수관이나 담장은 그대로 유지한다. 길을 다시 막는 잔해 충돌체는 생성하지 않는다.

개별 장애물 ID·파괴 사건·프레임별 파괴 상태를 기록한다.
리플레이 되감기는 충돌·외형·시야를 복원하며, 에피소드 리셋은 부분 손상까지 초기화한다.

## 현재 PC에서 사용

기존 실행 `20261117_063521`은 보존한다. 새 실행 `terrain_v2_20261117`과 별도 상대 정책 풀을 만들고,
최신 2,214,144스텝 체크포인트에서 재개했다. 게임은 새 소스로 다시 빌드한 `build/TankGame.exe`다.
검증에서 4,096스텝을 추가해 2,218,240스텝으로 저장했고, optimizer 갱신 16회와 CPU 재로딩을 확인했다.
교체 전 게임은 `build/TankGame_before_terrain_v2_20261117.exe`에 보관했다.

`training/python/resume_local.bat`로 자동 커리큘럼을 이어간다.
대시보드에서는 `terrain_v2_20261117`을 선택한다. 같은 실행을 중복 시작하지 않는다.
특정 코스만 연습하려면 시작 창의 **지형주행 시험공간**에서 선택한다. 고정 모드는 자동 승급하지 않는다.

```bat
training\python\resume_local.bat --terrain-course gates --timesteps 100000
```

자동 커리큘럼으로 돌아갈 때는 추가 인자 없이 실행한다.
원본 스냅샷의 구버전 실행 파일은 새 규칙을 지원하지 않으므로 학습 시작 시 오류로 알린다.
새 물리로 만든 에피소드의 재현에는 같은 버전 게임을 사용한다.
