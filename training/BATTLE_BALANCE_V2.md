# 전투 학습 balance v2

이 버전은 사료 수치 재현이 아닌 **학습 가능한 전술 관계**를 목표로 포·보상을 조정한다.

## 전차와 관통 조건

- 셔먼: 76.2mm 장포신과 확대 포탑. 내부 ID `sherman75`는 기존 모델의 전차 식별 입력을 유지하기 위한 호환 ID다.
- T-34: 85mm 포, 확대 포탑, 전차장과 포수가 분리된 5인 승무원. 내부 ID `t34_76` 역시 유지한다.
- 티거: 기존 차체 장갑 유지, 포방패 120 → 200mm.

연합군 주력 철갑탄·고속철갑탄을 실제 티거 형상에 사격하는 검사로 다음 조건을 맞췄다.
거리 50·100·250·500m에서 차체 상부/하부 정면의 관통확률 ≥95%, 차체 35°에서는 ≤1%다.
포방패는 연합군 탄을 막는다. 포탑 볼·포신·측후면 같은 약점까지 무적이 되는 설정은 아니다.
45°로 과하게 틀면 측면이 다시 취약해지므로 지정한 방어 자세는 35°다.

두 연합군 포는 자기 차체 정면도 관통할 수 있어 초기 동종 자기 대전이 피해 없이 끝나는 문제를 줄인다.
포구 속도·관통력·분산 편차는 게임 조정값이며, `tanks/data/*.json`과 보고서에 기록된다.

## 점진 보상

| 결과 | 보상 |
|---|---:|
| 팀 승리 | +200 |
| 팀 패배 | -80 |
| 시간 초과 | -35 |
| 적 전차 격파 | +25 |
| 관통 | +8 |
| 단순 명중 | +0.2 |
| 실제 모듈 손상 / 파괴 | +1.5 / +5 |
| 승무원 부상 / 전사 | +2 / +5 |

실제 피해는 피격자에게도 감점으로 반영한다. 이미 변한 모듈 상태를 다시 맞혀도 같은 변화 보상을 반복하지 않는다.

보조 보상은 다음과 같이 제한한다.

- **아슬아슬한 비관통**: 평균 관통력 / 실제 유효장갑 비율이 0.65~1.0으로 개선될수록 보상. 표적별 최고 품질 개선분만 지급하고 경기 전체 최대 +4.
- **근접 빗나감**: 표적 4m 이내의 근접 통과 품질과 예상 장갑 대비 관통 비율을 결합한다. 표적별 최고 품질 개선분만 지급하고 경기 전체 최대 +3. 정확한 거리·관통 정답을 정책 관측에 추가하지는 않는다.
- **실패 후 접근**: 비관통이 2회 반복되거나 20초간 관통·실제 피해가 없으면 활성화한다. 직접 이동해 이전 최단거리보다 가까워진 양에만 1m당 +0.05, 경기당 최대 +7. 150/100/60/30m 경계에는 +0.5/+1/+1.5/+2를 한 번씩 지급한다.
- 관통이나 실제 피해가 발생하면 접근 압력을 해제한다. 정지 장거리 사격이 성과를 내고 있으면 접근을 강제하지 않는다.

후퇴·재접근, 반복 도탄, 같은 근접 빗나감으로 보상을 무한 반복하지 못한다. 보조 보상 총 한도는 +19이며 승리 +200보다 작다.
단순 비관통 사격과 접근만으로 시간 초과를 이익으로 바꾸지 않도록 감점도 함께 설정했다.

## 기록과 타격 이미지

유효 명중은 타격 당시의 장갑면 형상, 포탑·포 자세, 장갑 입사 좌표와 실제 입사 방향을 기록한다.
전투 보고서 타격 행의 **타격 시뮬레이션**을 누르면 해당 탄착을 재생한다.

- `impacts/shot_NNNN.html`: 기록된 탄착의 재생, 확대 분석 이미지, 전체 피해 목록.
- `impacts/shot_NNNN.svg`: 실제 형상을 투영한 타격 지점·탄종·적 거리·관통 판정·피해 설명 이미지.
- `report.html`: 이미지를 내부에 포함해 단독 열람·인쇄가 가능하다. 상세 재생 링크도 쓰려면 `impacts` 폴더를 함께 옮긴다.

재생은 기록된 난수 결과를 유지한다. 사격 조건을 바꿔 다시 관통 판정을 내리는 기능은 아니다.
당시 형상이 없는 옛 기록에는 형상 누락을 명시하며, 현재 전차 형상을 옛 타격의 정답처럼 사용하지 않는다.

## 기존 학습의 처리

`BATTLE-1`은 비교용으로 저장 후 종료하고, 그 모델 가중치와 optimizer를 `BATTLE-2`의 초기값으로 사용한다.
새 보상과 포 제원에서 다시 평가하므로 단계 성공 통계는 새로 수집한다. 관측 크기 605개와 전차 식별 슬롯은 유지한다.
기존 balance v1 상태를 직접 재개해도 가중치는 유지하며 평가 통계는 초기화하고, 변경 사실을 `assessment_upgrade`로 남긴다.

`training/tests/run_combat_balance_tests.gd`는 관통 조건·보상 반복 방지·타격 이미지 연결을 검증한다.
변경 후의 실제 승률·무승부율 개선은 학습 기록으로 별도 확인해야 한다.
