기존 `training/python/runs`는 이 위치를 가리키는 디렉터리 연결로 유지했다.

모델이 있으면 `--resume`을 생략해도 자동으로 이어받는다.
모델 구조가 맞지 않거나 파일이 손상되면 새 모델로 덮어쓰지 않고 오류를 표시한다.
각 저장은 `checkpoints/step_.../`에 모델·커리큘럼·체크섬을 묶어 새로 만든다.
완료된 세대를 `checkpoint.json`이 가리키며 이전 세대를 자동 삭제하지 않는다.
`latest.zip`은 호환용 복사본이다. 재개는 검증된 세대 모델을 우선 사용한다.
학습 로그도 세션별 폴더에 추가하고 에피소드 번호를 이어가므로 과거 기록을 덮어쓰지 않는다.
같은 실행을 두 학습 프로세스가 동시에 수정하는 것은 잠금으로 막는다.
사용한 게임 실행 파일은 데이터 폴더의 `runtimes/<SHA-256>/`에도 보관한다.

## 실행과 확인

`training/python/dashboard.bat`를 실행하고 `su1117_02`를 선택한다.
대시보드에는 티거·셔먼 모델과 병합한 이전 기록이 함께 표시된다.
학습 중 버전을 바꿀 때는 **저장 후 중지**한 다음 새 실행 파일로 이어서 시작한다.
`resume_local.bat`는 복구된 티거를 이어 학습한다. 셔먼 학습 중에는 같은 실행을 중복 시작하지 않는다.
학습용 Python은 `training/python/.venv/Scripts/python.exe`다.

v2 모델의 가중치·optimizer·누적 스텝과 원래 기록은 유지하고, 달라진 주행 과제의 성적만 다시 평가한다.
이전 평가 집계도 `previous_assessments`에 남긴다.
관측 389개·행동 11개 규격을 유지한다.
