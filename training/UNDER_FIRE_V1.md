# 노출과 피격: 사격 인지 → 이동 → 엄폐

2026-11-17 수정. 적용 단계는 `m3_under_fire`, 평가 버전은 3이다.

## 입력과 포탄

기존 관측에도 포성·탄착·피탄 소리는 있었지만 최근 4개 소리 슬롯에 섞였고,
목적 관측에는 적의 발사를 식별하는 별도 항목이 없었다.
또한 기존 포탄은 비행 궤적 전체를 발사 순간에 추적해 피해를 즉시 적용했다.
이 방식에서는 발사를 알아챈 뒤 날아오는 그 탄을 피할 수 없었다.

새 관측 모드 `situation_v3`는 기존 419개 입력 뒤에 다음 **18개**를 추가한다.

| 단서 | 입력 |
|---|---|
| 들린 발사음 | 최근 정도, 차체 기준 방향 sin/cos |
| 눈으로 확인한 적 발사 섬광 | 최근 정도, 방향 sin/cos |
| 들린 탄착 | 최근 정도, 방향 sin/cos |
| 가까이 지나간 탄 | 최근 정도, 방향 sin/cos |
| 현재 보이는 비행 탄 | 존재, 방향 sin/cos, 이동 방향 sin/cos, 어림 근접도 |

방향은 5도 단위로 양자화한다. 자기 포성은 제외한다.
소리 입력은 들린 방향이며 숨은 발사자의 정확한 위치·신원은 주지 않는다.
섬광·비행 탄은 현재 시야와 실제 가림 판정을 통과해야 보인다.
적 재장전 시간, 포탄의 미래 탄착점, 숨은 적의 현재 위치는 입력하지 않는다.

이 단계에서는 포탄을 30Hz로 이동시키며, **충돌 시점의 전차 위치**로 명중을 판정한다.
벽에 막힌 탄은 벽을 통과하지 않으며, 아직 비행 중인 탄도 종료 해시에 포함한다.
리플레이 프레임에 비행 위치를 저장해 뷰어에서 이동하는 궤적을 표시한다.
새 리플레이에는 실제 학습 보상을 점수로 기록한다.

## 엄폐를 찾아야 하는 배치

모두 평지의 노출 지점에서 적을 향해 출발한다. 방향·좌우·거리·배치는 시드로 달라진다.
엄폐물 중심은 출발점에서 대략 55~105m 떨어져 있고, 초기 진행축에서 45m 이상 옆에 있다.
따라서 단순 직진·정지로 엄폐할 수 없다.

| 변형 | 배치와 학습 의도 |
|---|---|
| screened | 먼 옆쪽의 넓은 벽 뒤를 찾아 이동 |
| open_cover | 적 2대의 시선을 모두 막는 먼 엄폐 선택. 가까운 낮은 바위는 포탑을 가리지 못함 |
| crossing | 적 사선을 가로질러 65~95m 옆 엄폐로 이동 |
| ambush | 뒤·옆의 먼 엄폐를 찾아 방향을 바꾸거나 후퇴 |

정답 엄폐 위치·도착점 방향을 정책에 주지 않는다. 이 과제의 기존 공개 적 진영 웨이포인트도 끈다.
`cover_regions`는 검증과 보조 보상 계산에만 사용하며 정책 입력에 포함하지 않는다.
다른 장애물을 이용하더라도 실제 성공 조건을 충족하면 통과한다.

## 성공과 보상

다음 조건을 모두 충족해야 `covered_after_fire`로 성공한다.

1. 적 전차를 한 번 이상 직접 탐지한다.
2. 들을 수 있는 적 발사를 실제로 경험한다.
3. 출발점에서 35m 이상 이동한다.
4. 높은 실제 엄폐물에서 18m 이내에 위치한다.
5. 살아 있는 모든 적에게 차체와 포탑이 모두 가려진 상태를 **4초 연속** 유지한다.
6. 누적 피격이 4회 이하다.

목표 달성 +8, 피격당 −0.5. 적에게 노출된 동안 초당 −0.04를 추가한다.
정답을 관측에 주지 않는 대신 엄폐까지 통행 가능한 잔여 거리의 새 진행도(총 최대 2)와
실제 사선 차단의 새 개선분(총 최대 2)을 보조 보상으로 준다.
왕복으로 중복 획득하지 못하며, 미통과 과제의 보조 배율은 최소 0.2를 유지한다.
적에게 사격해 얻는 명중·관통·격파 보상은 이 단계에서 0이다.

실습에서는 **연습탄**을 쓴다. 실제 충돌·피격 횟수는 기록하되 승무원·모듈의 우발적 파괴는 적용하지 않는다.
5회 피격, 240m 구역 이탈, 100초 초과는 실패다.
적은 보이는 표적 방향에서만 제압사격하며 완벽한 조준을 기다리지 않는다.
연습탄·제압사격·비행 포탄은 이 단계 설정으로 활성화된다.

## 기존 학습 보존

기존 419개 입력의 가중치는 유지하고 추가 18개 열만 0으로 확장한다.
Adam의 해당 모멘트도 기존 열을 보존하고 새 열만 0으로 확장한다.
누적 스텝·기존 체크포인트를 보존하며 변환 모델은 `input_migrations/`에 별도로 저장한다.
변환 직후 추가 단서가 어떤 값이더라도 기존 입력에 대한 행동과 가치 출력이 같은지 검사했다.

평가 v2 실행을 재개하면 이미 통과한 주행 항목과 현재 주행 진행은 유지한다.
변경된 `m3_under_fire` 이후 평가는 `previous_assessments`에 보관하고 다시 평가한다.
현재 실행이 m3 이전이면 기존 학습 순서대로 계속 진행한다.
설정이 없는 예전 에피소드는 기존 즉시 탄도 방식을 유지해 재현할 수 있다.
