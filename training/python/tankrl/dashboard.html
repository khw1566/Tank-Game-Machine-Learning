커리큘럼 

    
단계 위에 마우스를 올리면 무엇을 학습하고 무엇을 하면 성공인지 보입니다.

    

    

    

  


  

    
커리큘럼 v4 지도 

    
칸 하나 = 변형 × 전차의 최근 40판 성공률(빨강 → 초록, 진한 초록 = 승급 기준 통과). 변형 × 전차가 모두 진한 초록이어야 다음 단계로 갑니다. 배지 = 그 단계를 학습 중인 모델.

    

    
모델 품질 표
      전차
      값

    
행 = 모델(공통 / 전차별) × 스텝 구간, 열 = 단계 · 변형. 학습 판과 복습 판(이전 단계를 가끔 다시 푸는 판)을 함께 집계하므로, 단계를 바꾼 뒤 이전 단계 실력이 유지되는지(망각 여부)가 같은 열에서 보입니다. 행 머리의 표시: ▶ 단계 변경 · ⑂ 전차별 분기.

    

  


  

    
기록 모음 · 보고서 
      

    
모든 실행의 학습 보고서·평가 보고서와, 전체 기록이 남은 경기의 보고서를 한곳에서 고르고 넘겨 봅니다. 줄을 누르면 아래에서 바로 열리고 ◀ ▶ 로 같은 조건의 다음 보고서로 넘어갑니다.

    

    

      

      

      

      

      

    

    

    

      
새 창에서 열기  

      
    

  


  

    
10단계 최종 시험 · 티거 1 대 연합군 6

    
선택한 실행의 저장 모델을 복사해 평가합니다. 셔먼 3대 + T-34 3대, 360m 맵, 200m 출발, 3분 제한. 7개체는 서로 다른 모델을 사용하며, 기존 모델이 없는 개체는 새 정책으로 초기화합니다.

    

    

    

    
빠른 교전 보상 v3: 명중 +5 · 관통 추가 +3 · 격파 추가 +12 · 지근탄 개선 최대 +1 · 거리 단축·근접 보너스.
