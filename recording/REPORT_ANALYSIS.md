# 전투·타격 보고서와 명중·지근탄 분포

전투 보고서와 개별 타격 보고서는 `ReportTheme`의 공통 색상·표·설명 영역을 사용한다. 개별 타격 페이지에서 탄착을 재생하고, 관통 판정과 승무원·모듈의 실제 상태 변화를 확인할 수 있다. 재생은 기록된 결과를 보여 주며 물리 판정을 다시 추첨하지 않는다.

## 사격에 따른 점수

새 기록의 `shot.r.reward_events`는 발사 보상과 탄착 보상의 목록이다. 각 항목에는 전차 이름, 팀, 사유, 증감값, 적용 직전 누적값(`before`), 직후 누적값(`after`)이 있다. 발사와 탄착 사이에 발생한 시간·승패·지속 조준 보상은 해당 사격의 점수에 합치지 않는다. 실제 PPO 보상 자체는 변경하지 않는다.

이전 기록은 같은 물리 틱에서 사격 관련 항목만 연결한다. 이를 추정치라고 표시하고, 직전·직후 누적값은 ‘미기록’으로 남긴다. 같은 틱의 여러 사격을 정확히 분리할 수 없으므로 현재 가중치로 점수를 재계산하지 않는다.

## 표적 중심 합성

- 명중은 `entry_local`, 지근탄은 최근접 시점의 `near_miss.local_point`를 사용한다.
- 원점은 표적 차체 중심이다. 다른 크기의 차종은 차체 반너비·반높이·반길이로 각각 정규화한다. 차체 경계는 ±1이다.
- 정면 투영은 X·Y, 상부 투영은 X·−Z다. 상부 투영의 위쪽이 전차 정면이다. 표적 자세를 통일한 분포이며 탄 입사 방향을 통일한 조준 오차판은 아니다.
- 기존 지근탄의 월드 좌표만 있으면 표적 자세를 보간해 변환한다. 이 좌표는 추정치로 표시한다. 좌표가 없는 표본은 제외한다.
- 점은 실제 표본이다. 배경 격자는 선택한 표본에서 구역별 관측 비율을 보여 준다. 점·격자에 마우스를 올리면 수치를 볼 수 있다.
- 차종, 명중/지근탄, 아군 포함 여부, 차체 주변 확대를 바꿀 수 있다. 확대 범위 밖 표본 수를 표시한다.

지근탄은 한 발에 대해 기록된 최근접 통과점이며, 표적 중심 12m 이내만 기록한다. 전체 리플레이를 남긴 경기만 포함하므로 전 학습 사격을 대표하지 않는다. 이 자료를 전체 명중 확률이나 미래 탄착 확률의 예측으로 해석하면 안 된다.

## 원자료와 재생성

각 보고서 옆에 `shot_distribution.csv`와 `shot_distribution.json`을 저장한다. 원자료에는 경기 UID, 사격 번호, 표적, 종류, 아군 여부, 차체 중심 좌표(m), 정규화 좌표, 사거리, 최근접 거리, 좌표 출처가 있다.

`recording/tools/rebuild_reports.gd`를 `--run=<실행 폴더> --out=<통합 분석 폴더>`와 함께 실행하면 완료된 보고서를 다시 만들고, 경기 UID로 재현본 중복을 제거한 통합 분포를 만든다. 대시보드 ‘기록 모음 · 보고서’에서 생성된 통합 분석을 연다.

검증 스크립트: `recording/tests/run_report_analysis_tests.gd`, `recording/tests/run_record_tests.gd`, `training/tests/run_attack_reward_tests.gd`.
